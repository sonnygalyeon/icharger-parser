# Расчёт энергии батареи

## Какие поля используются

Индексы считаются с нуля после удаления `$`. Пакет телеметрии 4010DUO содержит 22 поля.

| Индекс | Значение | Единица RAW | Преобразование |
|---|---|---|---|
| 2 | Время | ms | / 1000 → s |
| 5 | Ток батареи | 0.01 A | × 0.01 → A; разряд отрицательный |
| 6 | Входное питание | mV | / 1000 → V |
| 7 | Напряжение на силовом выходе | mV | / 1000 → V |
| 8 | Знаковый счётчик заряда | mAh | / 1000 → Ah |
| 11–20 | Напряжения десяти балансирных каналов | mV | / 1000 → V; ноль означает отсутствие измерения |
| 21 | Контрольная сумма | целое | XOR ASCII от `$` до последнего `;` включительно |

В первой строке `Discharge_32_CH1`:

- `4252` → **4.252 V** на силовом выходе;
- `4246` → **4.246 V** на первой банке;
- `24344` → **24.344 V** входного питания;
- ток в этой строке равен нулю, мощность также нулевая.

Два показания 4.252 и 4.246 V относятся к разным точкам измерения одной батареи. Для напряжения батареи суммируются **только балансирные каналы последовательных банок**. Число параллельных элементов лог не определяет.

## Ah и Wh

Для каждой пары соседних записей:

```text
Δt = (timestamp[i] - timestamp[i-1]) / 1000     [s]
P[i] = U[i] × I[i]                            [W]
ΔE = (P[i-1] + P[i]) / 2 × Δt / 3600         [Wh]
ΔQ = (I[i-1] + I[i]) / 2 × Δt / 3600         [Ah]
```

Принятая и отданная энергия накапливаются отдельно и показываются положительными числами. Интервал со сменой знака делится в точке нуля линейно интерполированной мощности (для Ah — тока). Поэтому заряд и разряд не уничтожают друг друга при подсчёте суммарного оборота.

Wh относятся к записанному участку испытания. Для оценки полной доступной энергии нужен полный разряд с известными начальным зарядом, током и порогом завершения. Балансировочный ток по каждой банке не записан: расчёт использует общий ток батареи. Номинальная энергия по маркировке отдельно не выводится.

## Источник напряжения

`--energy-voltage auto` (по умолчанию) использует сумму обнаруженных последовательных балансирных каналов, когда они присутствуют в каждом отсчёте без пропусков между номерами. Если данных нет или часть записей неполна, **весь расчёт** использует напряжение силового выхода. Источник указывается в HTML, CSV и сводке.

Обнаруженные каналы должны охватывать все последовательные банки. Формат пакета не даёт независимой гарантии этого; пользователь может выбрать `--energy-voltage output`. Режим `cells` требует полной записи всех обнаруженных каналов и возвращает понятную ошибку при её отсутствии.

Энергия на силовом выходе всегда рассчитывается отдельно. Разница с энергией по балансиру может включать падение напряжения на проводах/контактах и погрешности измерения. Автоматически приписывать всю разницу проводам нельзя.

## Качество данных

- Повреждённые пакеты и ошибки XOR попадают в список ошибок, их число видно в отчёте.
- Порог разрыва: `max(2.5 × медиана Δt, медиана Δt + 2 s)`. Большие интервалы не интегрируются, исключённое время указано явно.
- Повторная временная метка не добавляет энергию; повторы посчитаны отдельно.
- Файл с несколькими каналами не интегрируется как одна батарея: его нужно разделить по CH1/CH2.
- При полном отсутствии банок режим `auto` работает по силовому выходу.
- Счётчик Ah — модуль разницы конечного и начального счётчиков. В смешанных циклах это не сумма заряда и разряда; используйте раздельные интегралы.

| Показатель | Результат |
|---|---:|
| Пакеты телеметрии / статуса | 11 329 / 95 |
| Длительность | 11 328 s = 03:08:48 |
| Период | 1 s |
| Повреждённые пакеты / разрывы / повторы | 0 / 0 / 0 |
| Счётчик заряда | 36.324 Ah |
| Интеграл тока | 36.305925 Ah |
| Отдано по первой банке (1S) | 125.20946015 Wh |
| Отдано по силовому выходу | 100.5341467167 Wh |

Проверка другим способом, через среднее напряжение и приращение счётчика заряда (`Σ Uср × |ΔmAh| / 1000`), даёт 125.278314 Wh по банке и 100.5901335 Wh по силовому выходу. Небольшое расхождение связано с разными дискретными источниками заряда и способом интегрирования; эти результаты не подменяют основной интеграл U×I по времени.

## Совместимость CSV

Существующие `pack_voltage_v`, `power_w`, `energy_throughput_wh`, `integrated_energy_wh_signed` и `summary.csv:energy_wh` сохраняют источник **силовой выход**. Добавлены:

| Поле | Смысл |
|---|---|
| `battery_voltage_v`, `battery_voltage_source` | Напряжение для расчёта батареи и его источник |
| `cell_sum_voltage_v`, `voltage_difference_v` | Полная сумма измеряемых банок и разность с выходом |
| `battery_power_w` | Знаковая мощность батареи |
| `discharge_energy_wh`, `charge_energy_wh` | Отданная и принятая энергия батареи |
| `output_discharge_energy_wh`, `output_charge_energy_wh` | Раздельная энергия силового выхода |
| `battery_energy_throughput_wh` | Суммарная энергия заряда и разряда батареи |
| `battery_energy_wh_signed` | Заряд минус разряд батареи |
| `energy_difference_wh` | Разряд батареи минус разряд силового выхода |
| `discharge_capacity_ah`, `charge_capacity_ah` | Раздельные интегралы тока |
| `integration_dt_s`, `integration_omitted_s` | Учтённое и исключённое время интервала |

В JSON и `summary.csv` поле `battery_energy_wh` — итог `battery_energy_throughput_wh`. При смене направления тока исправлен подсчёт оборота без взаимного вычитания направлений. Значения существующих интегралов при больших разрывах теперь не включают неизвестные участки; исключённая длительность всегда выводится.
