# 🔋 iCharger Analyzer

**Преобразование TXT/LOG-файлов iCharger в интерактивные HTML-графики и CSV**

Один лог — отдельный отчёт. Несколько логов — общий сравнительный график.

</div>

---

## Что делает программа

iCharger Analyzer читает журнал испытания аккумулятора и строит понятный отчёт с графиками:

- напряжение аккумулятора и входного питания;
- ток и мощность;
- отданная или принятая ёмкость;
- накопленная энергия;
- отданная и принятая энергия батареи в **Wh**, отдельно от энергии силового выхода;
- внутренняя и внешняя температура;
- напряжение каждой банки;
- минимальная банка и разбаланс;
- период записи, частота отсчётов и разрывы телеметрии.

При обработке нескольких логов программа создаёт общий отчёт, где каждый файл показан отдельной линией.

## Быстрый запуск

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

python main.py "log.txt" -o output
```

### Windows

```bat
py -3 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt

python main.py "log.txt" -o output
```

> Пути с пробелами и квадратными скобками заключайте в кавычки.

## Примеры

Один файл:

```bash
python main.py "examples/LiPo[Discharge_6_CH1]_copter_6s.txt" -o output
```

Несколько файлов:

```bash
python main.py "battery_1.txt" "battery_2.txt" "battery_3.txt" -o output
```

Все `.txt` и `.log` из папки:

```bash
python main.py "./logs" -o output
```

Задать шаг общего графика вручную:

```bash
python main.py "./logs" -o output --comparison-step 5
```

Не создавать CSV:

```bash
python main.py "log.txt" -o output --no-csv
```

Использовать Plotly через Интернет и уменьшить размер HTML:

```bash
python main.py "log.txt" -o output --cdn
```

## Результат

Для каждого лога создаются:

```text
<имя>_report.html
<имя>_telemetry.csv
<имя>_status.csv
```

При обработке нескольких файлов дополнительно создаются:

```text
index.html
comparison_telemetry.csv
summary.csv
```

`index.html` содержит общее сравнение по времени и нормированное сравнение от 0 до 100%.

## Особенности

- исходные TXT/LOG-файлы не изменяются;
- повреждённые строки не останавливают обработку всего файла;
- индивидуальные отчёты используют все исходные точки;
- общий отчёт автоматически выбирает подходящий шаг;
- HTML по умолчанию автономный и открывается без Интернета;
- CSV подходит для Excel, Python, MATLAB и других программ.

## Энергия батареи в Wh

Энергия считается по всем отсчётам как интеграл **напряжение × ток × время**. По умолчанию используется полная сумма напряжений банок. Если балансирные данные отсутствуют или неполны, используется напряжение силового выхода с явной отметкой в отчёте.

```bash
python main.py "log.txt" -o output --energy-voltage auto
python main.py "log.txt" -o output --energy-voltage cells
python main.py "log.txt" -o output --energy-voltage output
```

Карточки показывают Wh батареи, Ah по счётчику, Wh силового выхода и длительность. Раздельные интегралы заряда/разряда, источники напряжения и формулы доступны в раскрывающемся блоке. Большие разрывы телеметрии исключаются из интеграла с указанием пропущенного времени.

Точное описание полей, ограничений и проверка на `Discharge_32_CH1`: [docs/energy.md](docs/energy.md).

## Управление графиками

Каждый график находится в отдельной карточке со своими настройками:

- **X + / X −**, **Y + / Y −** — масштаб по горизонтали и вертикали;
- **Масштаб / Позиция** — ползунки размера и положения окна;
- нижний обзор графика — перемещение окна и изменение его границ;
- **← / →** — сдвиг выбранного участка;
- **Авто Y** — вертикальный масштаб по видимым линиям на выбранном участке;
- **Выделение** — увеличение области мышью, повторное нажатие возвращает перемещение;
- **Сброс**, **Развернуть**, **Esc** — восстановление диапазона и работа на весь экран;
- выпадающий список и **↑ / ↓** — переход между графиками;
- легенда и встроенная панель Plotly — управление линиями и сохранение изображения.

Графики загружаются по мере прокрутки. Свои масштабы и настройки есть также у каждого графика общего сравнения. Подробные таблицы, предупреждения и JSON свёрнуты по умолчанию.
